# Security Policy

## Supported Versions

Only the latest release of Diceware receives security fixes. See [Releases](https://github.com/hastefuI/diceware/releases) for the current version.

## Reporting a Vulnerability

See [GitHub's private vulnerability reporting](https://github.com/hastefuI/diceware/security) feature for this repository to report a vulnerability.

Provide as much detail as possible to help reproduce the issue and assess impact.
